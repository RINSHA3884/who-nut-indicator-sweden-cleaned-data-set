# WHO Nutrition Indicators Dataset — Switzerland

## Project Overview

This project focuses on the preprocessing and cleaning of nutrition indicator data for Switzerland, sourced from the World Health Organization (WHO) Global Health Observatory (GHO).

The objective is to prepare raw public health data for reliable analysis and visualization using Microsoft Excel and Power BI. The dataset contains nutrition-related indicators, observations across multiple years, and demographic dimensions.

## Dataset Description

The dataset includes the following fields:

| Column | Description |
|---|---|
| GHO Code | Code identifying the WHO health indicator |
| Category | Category associated with the indicator |
| Indicator | Nutrition indicator, such as overweight, obesity, or thinness |
| Year | Year of the reported observation |
| Region | WHO region associated with the observation |
| Country | Country covered by the dataset (Switzerland) |
| Dimension | Population group, including female, male, and both sexes |
| Found Value | Observed value reported for the indicator |
| Normal Value | Reference or normal value, where provided |
| Low Value | Lower reference value, where provided |
| High Value | Upper reference value, where provided |

## Data Preprocessing

The project follows a structured data-cleaning workflow in Microsoft Excel.

Planned preprocessing tasks include:

- Checking and removing verified duplicate records.
- Identifying and handling missing values appropriately.
- Standardizing data formats and column data types.
- Reviewing numerical fields for inconsistencies.
- Creating calculated fields where analytically appropriate.
- Filtering and sorting records for validation.
- Preparing a structured dataset for further analysis.

Only preprocessing steps completed and verified should be marked as completed in the final project documentation.

## Potential Analysis

The cleaned dataset can support further analysis, including:

- **Trend Analysis:** Examine changes in nutrition indicators over multiple years.
- **Gender-Based Analysis:** Compare reported values for female and male populations.
- **Indicator Analysis:** Explore indicators such as overweight, obesity, and thinness.
- **Data Quality Analysis:** Assess missing values, duplicate records, and consistency.
- **Reference Value Analysis:** Examine observed values against supplied reference values where their meaning and applicability are established.

## Tools Used

- **Microsoft Excel:** Data cleaning, preprocessing, sorting, filtering, and PivotTables.


## Project Workflow

1. Obtain the raw WHO nutrition indicator dataset.
2. Inspect the dataset structure and data quality.
3. Perform preprocessing and cleaning in Excel.
4. Validate the cleaned data.
5. Prepare the cleaned dataset for analysis.
6. Develop visualizations and dashboards in Power BI.

## Expected Outcome

The expected outcome is a clean, structured, and analysis-ready dataset that supports the exploration of nutrition indicators in Switzerland across years and population groups.

This project demonstrates practical skills in data preprocessing, data quality assessment, spreadsheet operations, and preparation of public health data for business intelligence reporting.

World Health Organization (WHO) — Global Health Observatory (GHO).
